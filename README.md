> 💡 **小书房是什么？**
> 一款免费的手机应用，帮你把家里的纸质书记进手机：扫一下书背后的条形码，书名、作者、出版社、封面就会自动填好。以后想找某本书放在哪、借给谁了，打开小书房一查就知道。

## ✨ 它能做什么

- 📷 **录入**：扫码 ISBN、连续扫描、批量队列、拍照识字（封面 / 扉页 OCR），书名作者出版社自动补全
- 🗄️ **书架浏览**：像逛书架一样翻看藏书，列表 / 封面网格 / 纯文字三种视图，搜索、筛选、11 种排序
- 🏷️ **整理**：分类（两级）/ 标签 / 存放地点 / 系列，智能书架（在读、借出中、超期、待完善…），支持日期与价格区间筛选
- 📍 **记录位置**：这本书放在书房还是客厅？记下来，一搜就能找到，不用到处翻
- 🤝 **借阅管理**：应还日期、到期通知、借阅人联系方式、一键复制催还文案、归还确认
- 📖 **阅读记录**：开始 / 读完日期、阅读进度、年度目标；摘抄、批注、书评按时间线保存
- 📚 **系列 / 套装**：给多卷本记上系列名和卷号，自动按阅读顺序收好、提示缺哪一卷，套装价还能一键分摊写回
- 🛒 **想读清单**：买之前先记下书名、作者、优先级、心理价，买到后一键转为藏书
- 🧹 **盘点模式**：扫一遍书房，结束给出缺失 / 多出清单，可一键标记遗失
- 📤 **分享**：单本书生成藏书票图片，多选生成文字书单
- 📊 **藏书统计**：一共多少本书、最贵的书是哪本、最喜欢哪个作者；购书统计按月 / 年 / 总看购入、录入与花费
- 🔒 **应用锁**：可选开启，用手机的指纹 / 面容或锁屏密码保护书架，离开 1 分钟后自动锁定
- 🌈 **多套主题**：7 套配色（含夜读深色），每套有独立纸色
- ☁️ **备份恢复**：zip 全量备份（含图片 / 借阅 / 摘抄）与 Excel 清单导出

## 📲 下载安装

1. 打开 [**Releases 下载页**](https://github.com/BaiDuRen69/Bookshelf/releases/latest)，下载 `XiaoShuFang-v5.0.apk`
2. 在手机上点开下载好的文件（若提示「不允许安装未知应用」，按手机提示允许即可）
3. 安装完成，打开小书房，开始扫第一本书 🎉

> 📱 需要 Android 7.0 或以上版本；应用完全免费，无广告，不需要注册账号。安装包为 ARM 架构（arm64-v8a / armeabi-v7a），x86 平板或模拟器请使用 debug 构建。

## 🚀 三步开始使用

**第一步：扫码添加书** —— 打开 App 点「扫码」，对准书背后的条形码，「嘀」一声书就进书架了。

**第二步：告诉它书在哪** —— 添加时选一下存放位置（书房、客厅……），以后一搜就能找到。

**第三步：开个自动备份** —— 在「我的 → 自动备份」里打开开关，藏书数据会定期自动备份，安心省心。

## 💾 你的数据很安全

- 所有藏书数据**只保存在你自己的手机里**，不上传任何服务器，不需要注册登录
- 可在「我的 → 设置 → 应用锁」开启指纹 / 面容或手机锁屏密码，离开 1 分钟后自动锁定
- **zip 自动备份**是真正的全量备份（含图片、借阅记录、摘抄），建议开启
- **Excel 导出**适合查看和分享书单，但它不含借阅记录等信息，不能替代 zip 备份
- 换新手机时：旧手机导出 zip 备份 → 新手机「导入备份」→ 藏书完整迁移

## ❓ 常见问题

<details>
<summary><b>扫码后搜不到这本书？</b></summary>
<br>

少数书籍（尤其是个别小众出版物）的数据库里没有收录。你可以在录入页手动填写书名等信息，一样能收藏。也可以在「我的 → API 设置」中配置图书查询数据源来提高识别率（见下方「技术信息」），不配置不影响使用。
</details>

<details>
<summary><b>换手机了，藏书怎么迁移？</b></summary>
<br>

旧手机：我的 → 备份文件管理 → 选一份备份 → 分享到应用外（微信文件传输助手 / 网盘均可）。
新手机：安装小书房 → 我的 → 导入备份 → 选择 zip 文件 → 完成。
</details>

<details>
<summary><b>误删了书还能找回吗？</b></summary>
<br>

用最近一次的 zip 备份恢复即可找回（「我的 → 导入备份」）。注意恢复会覆盖当前数据，所以开启自动备份很有必要。
</details>

## 🛠️ 技术信息（开发者 / 进阶用户）

<details>
<summary>点击展开：技术栈、构建方式与数据源配置</summary>

### 技术栈

原生 Android（Java）· Room（18 版保数据迁移）· CameraX 1.4.2 + ML Kit 17.3.0（条形码识别）+ ML Kit 文本识别 16.0.1（封面 OCR，
原生库均已适配 Android 15+ 的 16 KB 内存页）·
Retrofit · Glide · 零依赖手写 XLSX 读写器（不引入 POI）· EncryptedSharedPreferences（API 密钥加密存储）· androidx.biometric（应用锁）
当前版本 v5.0（versionCode 95，Room 数据库 v18）。

### v5.0 里程碑

- v5.0 本身不新增功能，是 v4.23 之后的一次稳定收口：把视觉体系、系列 / 套装、应用锁、OCR、摘抄、想读、盘点、借阅提醒、阅读记录、批量扫码等能力合并为一个版本。
- 书架改用 DiffUtil 增量刷新；新增 24 个纯逻辑单元测试；`lintDebug` 0 error。
- 数据库仍为 v18，覆盖安装 / 从 v4.x 升级均保留全部藏书、借阅、摘抄与备份设置。

### v4.55 代码质量与性能

- **书架增量刷新**：列表 / 封面网格 / 纯文字三种视图改用 DiffUtil，只重绑真正变化的行；多选时只刷新选中态变化的卡片，不再整表闪烁与重复加载封面。
- **结构收敛**：智能书架 9 类判定与计数抽到 `util/SmartShelf`，日期键与购入日期精度展开抽到 `util/DateKeys`，书架页只保留 UI 与筛选编排。
- **测试**：新增 24 个纯逻辑单元测试（系列分组/排序/缺卷、日期键、智能书架、字段清洗、套装分摊），`gradle :app:testDebugUnitTest` 全绿。
- **静态检查**：`lintDebug` 0 error；修掉 Locale 隐患、`app:tint`、include 布局参数、通知权限显式检查，并把应用锁的返回键迁移到 `OnBackPressedDispatcher`。
- 本轮不改数据库（仍 v18），不影响已有藏书。

### v4.54 应用锁

- 「我的 → 设置 → 应用锁」：开启后用手机的指纹 / 面容或锁屏密码进入小书房，**不另设应用密码**，忘记手机密码也不会多一个找不回的密码。
- 离开小书房超过 1 分钟再回来会重新锁定；拍封面调起系统相机、相册、文件选择器等短暂跳出，1 分钟内回来不会打扰。
- 冷启动（包括进程被系统回收后重新打开）一定要求解锁；所有页面统一拦截，不能从最近任务或二级页绕过。
- 手机没有设置锁屏密码/指纹时，会先引导去系统设置；如果之后把手机锁屏方式删掉，锁屏页会给出「关闭应用锁」的出口，避免把自己锁在外面。

### v4.53 系列 / 套装分组

- 编辑书籍时填写「系列」和卷号，系列名可从已有系列里点选，卷号留空时会自动带出下一卷。
- 「我的 → 系列书架」把多卷本 / 套装收在一起：按阅读顺序排列、显示已读进度、自动提示缺哪一卷；点系列名可重命名，同步更新系列内全部藏书。
- 系列页可直接「添加下一本」（自动带上系列名和下一卷），也可以「套装分摊」：按定价比例分摊实付总额，并一键把结果写回每本书的购入价。
- 书架「更多筛选」新增系列筛选；详情页有系列入口；搜索系列名也能找到书；Excel 导出 / 导入新增「系列 / 卷号 / 阅读顺序」三列。

### v4.52 分享书卡 / 书单

- 详情页右上「更多 → 分享书卡」：把这本书生成一张 1080×1440 的藏书票图片（封面、书名、作者、评分、标签、书摘），可直接发微信/朋友圈。
- 书架长按多选后点「分享」：把选中的书生成文字书单。

### v4.51 拍照识字

- 「我的 → 拍照识字」：拍封面/扉页或从相册选一张，自动识别书名、作者、出版社，并把这照片直接当封面。
- 识别结果只做预填，打开录入页后仍可修改；没买到条码的冷门书也能少打很多字。
- 「扫码录入 → 从图片识别」如果图片里没有 ISBN，会自动转为文字识别，同样带进录入页。
- 说明：这版安装包只包含 ARM 架构（arm64 / armv7），OCR 模型较大，APK 约 37 MB。

### v4.50 摘抄 / 笔记 / 书评

- 详情页新增「摘抄与书评」：先看到自己的短评和最近两条摘抄，点进去是完整时间线。
- 摘抄支持页码、原文、批注、标签和一张配图；点条目编辑，长按删除，右上角可把这条摘抄分享成文字。
- 书架搜索会一起搜摘抄原文、批注、标签和短评——记得一句金句也能找到是哪本书。
- 摘抄和短评都会进整包备份，换手机恢复后还在。

### v4.49 扫码页修复 + 想读清单打磨

### v4.44 阅读记录与年度目标

### v4.43 扫码队列 + 批量录入

- 扫码页右上角打开「批量」：一本接一本扫，书自动进待录入列表，不再每本都跳编辑页。
- 扫完点「已加入 N 本」打开列表：能看到封面/书名、重复的书会标「已在书架」，可以移除误扫的。

### v4.42 借阅到期提醒 + 智能书架

- **借出时填应还日期**（默认 30 天后，可清空）；逾期后详情页红字提示，一点复制催还文案。
- **到期通知**：每天上午 9 点检查一次，「今天到期 / 已逾期」合成一条本地通知；Android 13+ 首次借出会请求通知权限，拒绝也不影响使用（书架有超期入口）。
- **借阅人档案**：可以给常用借阅人记录电话/微信，借出时直接看到。
- **智能书架**：筛选条下一排入口——在读、借出中、超期、最近购入、未评分、无封面、无地点、待完善、遗失，都带数量，点一下只看这一类，再点一次取消。

### v4.41 搜索更聪明，整理更省事

- **拼音搜索**：输入 `hlm`、`hongloumeng` 或 `hong` 都能找到《红楼梦》；大小写、空格、标点都不影响（`978-7-115` 与 `9787115` 等价）。书名/作者里命中的部分会高亮。
- **搜索防抖**：连续打字时 150ms 才刷新一次，书架不再逐字符重排。
- **筛选状态看得见**：应用筛选后，头部显示「共 N 本 · 已筛选 X 项」，右侧固定「清除」一点就回到全部；搜不到书时，空态直接给「清空搜索」按钮。
- **重复 ISBN 不再只能改旧书**：弹窗新增「增加一本副本」（数量 +1，并沿用本次填写的地点/购入信息）和「仍然新建一本」。
- **批量设置**：多选后可以一次改存放地点、给一批书加标签、设置阅读状态。
- **「我的阅读」更名「购书统计」**：这页统计的是购入/录入/花费，名字终于对得上了。

### v4.40 日期选择更简单

- **筛选里的日期换成自绘日历**：点「购入日期 / 录入日期」弹出月份日历，点开始、点结束就选好一段（点反了会自动对调），跨天区间用连续色带标出；顶部实时显示「2026-10-01 至 2026-10-22 · 共 22 天」。
- **一键区间**：日历里给「本月 / 近3月 / 今年 / 去年」四个快捷选项，点一下直接生效，不用再滚三次轮子。

Android Studio 打开本目录直接同步即可；或命令行：

### ISBN 数据源配置

ISBN 数据源在「我的 → API 设置」中填写，支持三种鉴权方式（默认腾讯云市场签名）。
密钥使用 AndroidKeyStore 加密存储，不会明文落盘。
这个 API 可以到腾讯云或阿里云搜索 ISBN，然后找到 ISBN 图书查询类似的服务购买即可，部分云服务是免费的但是数据不全或错误，可自行探索。
已适配腾讯云市场「聚美智数 ISBN 书号查询」（产品 ID 34136）（我目前使用的就是这个 https://market.cloud.tencent.com/products/34136 ）：

1. 鉴权方式选「腾讯云市场签名（SecretId+SecretKey）」
2. 请求地址填 API 接口调用地址，例如 `https://ap-guangzhou.cloudmarket-apigw.com/service-ed62t9xo/isbn/query`
3. SecretId / SecretKey 在腾讯云控制台 → 云市场（我的资源） → 已购产品与服务 → 管理 → 应用信息
4. 未配置时不影响使用：扫码后直接进入手动录入
